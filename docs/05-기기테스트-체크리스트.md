# 실기기(Galaxy Z Flip 6) 검증 체크리스트

샌드박스에서는 카메라·센서·커버 화면·NPU를 검증할 수 없으므로, 기기에서 아래 순서대로 확인한다.
각 항목은 **명령 또는 화면 조작 + 기대 결과** 형태로 되어 있고, 실패 시 기록할 위치를 함께 적었다.

## 0. 설치 및 로그

```bash
./gradlew :app:assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
adb logcat -s AIProController AIProCapability AIProBackend AIProEnhancer AIProQueue
```

* 앱 실행 → 카메라 권한 허용(동영상은 마이크도 허용).
* `AIProCapability` 로그에 카메라별 `raw=`, `manual` 지원 문자열이 찍히는지 확인.

## 4. 수동(프로) 설정

| # | 조작 | 기대 결과 |
|---|---|---|
| 4.1 | PRO 패널 열기 | 기기가 지원하는 항목만 표시(예: RAW 미지원 기기면 RAW 칩 없음) |
| 4.2 | ISO 수동 800 | 화면이 밝아지고, 저장 사진의 EXIF ISO ≈ 800 |
| 4.3 | 셔터 1/8 | 모션 블러 발생, EXIF exposure ≈ 0.125s |
| 4.4 | MF 슬라이더 | 초점이 실제로 이동(근거리/무한대) |
| 4.5 | WB 3200K → 8000K | 화면 색온도가 파랑→주황으로 변함 |
| 4.6 | EV -2 → +2 | 밝기 변화, 0으로 복귀 시 원상 |
| 4.7 | 수동 설정 후 렌즈 전환 | 설정이 자동으로 초기화되고 프리뷰 정상 |

> 4.2~4.6은 `ManualSettings.normalize()`가 기기 실측 범위로 클램프하므로, 하드웨어가 거부하는 값은
> 애초에 UI에 나타나지 않는다. 값이 이상하면 `지원 정보` 시트와 대조한다.

## 12. 실험적 수평 잠금 (6단계)

| # | 조작 | 기대 결과 |
|---|---|---|
| 12.1 | 자이로/가속도 센서 유무 | 센서가 없으면 `수평잠금` 칩 자체가 표시되지 않음 |
| 12.2 | `수평잠금` 칩 켜기 | 실시간 처리도 함께 켜짐, 칩 라벨에 현재 롤 각도 표시 |
| 12.3 | 폰을 ±10° 기울이기 | 프리뷰 수평이 유지되고(줌 소폭 증가), 각도 표시가 실제 기울기와 일치 |
| 12.4 | 과격한 회전 | ±25°를 넘으면 보정이 멈추고 상태 문구가 `동작 감지 · 보정 완만`으로 바뀜 |
| 12.5 | 수평 잠금 + 동영상 녹화 후 후처리 | Enhanced 영상에 롤이 반영, `Video/Original`은 손대지 않음 |
| 12.6 | 정지 사진 | 원본은 회전되지 않고 사이드카에 `horizonRollDegrees`만 기록됨(의도된 동작) |

## 13. 화질/비율 · 프리뷰 · 수평 잠금 (7차 수정)

| # | 조작 | 기대 결과 |
|---|---|---|
| 13.1 | 세로로 들고 프리뷰 | 상하/좌우가 뒤집히거나 늘어나지 않음(4:3 선택 시 3:4 박스로 레터박스) |
| 13.2 | 상단 비율 → 1:1 / 4:3 / 16:9 / 22:9 | 프리뷰 박스 비율이 즉시 바뀌고, 촬영 결과 JPEG 비율이 선택값과 일치 |
| 13.3 | 22:9 촬영 → EXIF 확인 | 해상도가 4000×1636 등 정확히 22:9로 크롭됨(`croppedToRatio`는 사이드카 참고) |
| 13.4 | 동영상 모드에서 비율 시트 | 이 기기가 지원하지 않는 비율은 "이 기기 동영상 미지원"으로 비활성 |
| 13.5 | 전면 카메라 전환 | 미러 프리뷰가 자연스럽고 회전 정상(뒤집힘 없음) |
| 13.6 | 수평잠금 켜기 → 폰 기울이기 | **화면이 멈추지 않고** 프리뷰가 부드럽게 회전, 인공 수평선 표시 |
| 13.7 | 플래시 버튼(플래시 있는 카메라) | 꺼짐 → 자동 → 켜짐 순환, 수동 ISO/셔터 사용 중에는 플래시가 동작하지 않음(로그로 확인) |
| 13.8 | 상단 톱니 → 스타일 전환 | 갤럭시 스타일 / 프로 스타일 전환 시 두 레이아웃 모두 프리뷰가 정상 크기로 표시 |
| 13.9 | 1:1 → 4:3 → 16:9 → 22:9 순환 | **어떤 비율에서도 피사체가 늘어나거나 납작해지지 않고**, 프리뷰 박스만 커지고 작아짐 (8차 수정 핵심 확인 항목) |
| 13.10 | 4:3에서 휴대폰을 15° 기울임 | 원(둥근 물체)이 타원이 되지 않음 = 비등방 왜곡 없음 |
| 13.11 | 사진 모드에서 수평잠금 켜고 기울이기 | 프리뷰가 실시간으로 수평에 맞춰 회전(수평선이 화면 수평과 나란해짐), 버벅임 없음 |
| 13.12 | 수평잠금 켠 채 기울여서 촬영 → 결과 확인 | 저장된 사진도 수평으로 보정되어 있고, 빈 모서리(검은 삼각형)가 없음 |
| 13.13 | 같은 상황에서 동영상 촬영 | 원본 mp4는 촬영 시 자세 그대로, `보정본`(후처리 작업)이 수평 보정되어 생성됨 |
