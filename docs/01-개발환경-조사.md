# 1단계 사전 조사 — 개발 환경

조사일: 2026-11-07 · 작업 환경: Linux(Debian 13) 샌드박스

## 1. 제공된 환경에서 확인된 사실

| 항목 | 상태 | 비고 |
|---|---|---|
| OS | Debian GNU/Linux 13 (trixie), x86_64 | |
| JDK | 없음(기본 Java 11) → **Temurin JDK 17.0.21 별도 설치** | AGP 8.7은 JDK 17 필수 |
| Android SDK | 없음 → **cmdline-tools + platform 35 + build-tools 35.0.0 설치** | |
| NDK / CMake | 없음 → **NDK 27.0.12077973 + CMake 3.22.1 설치** | |
| Gradle | 없음 → **Gradle 8.9 설치** | AGP 8.7.3과 호환 |
| 네트워크 | Google Maven / Maven Central 접근 가능(200) | 의존성 해석 가능 |
| 디스크 | 루트 25GB, `/tmp` **992MB tmpfs** | JVM `java.io.tmpdir`가 `/tmp`라 NDK 해제 실패 → `-Djava.io.tmpdir` 재지정으로 해결 |
| 실제 기기(Galaxy Z Flip 6) | **연결 불가** | 이 샌드박스에는 USB/ADB 기기가 없다 |

## 2. 이 환경의 한계 (반드시 기억할 것)

* 카메라·센서·커버 화면·NPU는 **에뮬레이터/샌드박스에서 검증 불가**. 실기기 검증 항목은
  `05-기기테스트-체크리스트.md`로 분리했다.
* 따라서 1단계에서 "검증 완료"라고 말할 수 있는 범위는 다음과 같다.
  1. 프로젝트 구성·Gradle 빌드(assembleDebug) 성공
  2. JVM 단위 테스트 성공 (카메라 없이 검증 가능한 순수 로직)
  3. C++ 코어의 호스트(데스크톱) 컴파일 및 테스트 성공
  4. NDK/CMake를 통한 arm64-v8a `.so` 실제 생성
* 실기기에서만 확인 가능한 것(Camera2 동작, RAW 지원 여부, 커버 화면, 발열)은
  **"미검증"으로 문서에 명시**하고, 앱이 런타임에 스스로 판정하도록 설계했다(가짜 UI 금지 원칙).

## 3. 빌드 재현 방법

```bash
export JAVA_HOME=<jdk17>
export ANDROID_HOME=<sdk>
export ANDROID_SDK_ROOT=<sdk>
cd AIProCamera
./gradlew :app:assembleDebug          # APK 빌드 + NDK 빌드
./gradlew :core:camera:testDebugUnitTest   # 순수 로직 단위 테스트
g++ -std=c++17 -O2 -I core/native/src/main/cpp \
    core/native/src/main/cpp/aipro_core.cpp \
    core/native/src/testHost/host_test.cpp -o /tmp/native_test && /tmp/native_test
```
