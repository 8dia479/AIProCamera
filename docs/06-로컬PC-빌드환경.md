## 2. 최초 상태와 조치

| # | 발견된 상태 | 조치 |
|---|---|---|
| 1 | SDKM에 `platforms/android-37.0`·`build-tools/36.0.0`만 있고 **platform-35 / build-tools 35.0.0 / NDK / CMake 없음** | `cmdline-tools` 설치 후 `sdkmanager`로 `platforms;android-35`, `build-tools;35.0.0`, `ndk;27.0.12077973`, `cmake;3.22.1` 설치 완료 |
| 2 | Android Studio 번들 JBR이 **Java 25** → Kotlin이 `IllegalArgumentException: 25.0.4`로 즉사 | 설치돼 있던 **JDK 21**(`C:\Program Files\Java\jdk-21.0.10`) 사용 |
| 3 | 프로젝트에 `gradle/gradle-daemon-jvm.properties`(`toolchainVersion=25`)가 있어 **Gradle 데몬 JVM을 25로 고정** → `org.gradle.java.home`이 무시됨 | 파일을 `gradle-daemon-jvm.properties.java25.bak`로 백업·이동 |
| 4 | 이전 Android Studio 템플릿 잔여물(`com.eightdia.aiprocamera` 테스트, `values-night/themes.xml`의 `Theme.MaterialComponents.*`, `mipmap-*`, `xml/backup_rules.xml` 등) 때문에 `processDebugResources` 실패 | `app\src` 삭제 후 저장소 소스만 재배치, `core/native/.cxx` 삭제(캐시 재생성) |
| 5 | 기본 `gradle.properties`가 2GB CI 프로파일 | PC용으로 `-Xmx5g`, `parallel=true`, `workers.max=6`, `kotlin.incremental=true` + `org.gradle.java.home` 지정 |

> Android Studio에서 직접 열어 빌드할 때도 **Settings → Build, Execution, Deployment → Build Tools → Gradle → Gradle JDK = 21** 로 맞춰야 한다.
> Studio가 `gradle-daemon-jvm.properties`를 다시 만들면 같은 문제가 재발하므로 그때는 다시 21로 바꾸거나 파일을 지운다.

## 3. 빌드 절차 (PC)

```bat
cd /d C:\Users\ailri\AndroidStudioProjects\AIProCamera
set JAVA_HOME=C:\Program Files\Java\jdk-21.0.10
set PATH=%JAVA_HOME%\bin;%PATH%
call gradlew.bat :app:assembleDebug :app:assembleRelease ^
     :core:camera:testDebugUnitTest :core:ai:testDebugUnitTest --console=plain
```

## 5. 아직 하지 않은 것

* **APK 설치/실행**: 사용자가 게임 중이라 요청대로 하지 않았다. 준비된 명령은 아래.
  ```bat
  "%LOCALAPPDATA%\Android\Sdk\platform-tools\adb.exe" install -r ^
      C:\Users\ailri\AndroidStudioProjects\AIProCamera\app\build\outputs\apk\release\app-release.apk
  ```
* **실기기 카메라 검증**: `docs/05-기기테스트-체크리스트.md` 절차대로 별도 진행 필요(카메라/RAW/커버화면/NPU/발열).
